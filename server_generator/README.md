# Introduction
All files in `server_generator` are for generating server stub files located in `libs/digivine-api-server`. Currently, we use `Openapi generator 5.4` because of the special variable names [issue](https://github.com/OpenAPITools/openapi-generator/issues/13867). 

# Customizing using templates 
1. Change templates in dir `templates/`
   - Default templates can be fetched by script `scripts/fetch_default_templates.sh`
   - Variables' values in `models.mustache` can be found in `debug/models_context` 
     
     They are separated by their model names. The original JSON file can be generated by script `scripts/generate_models_context.sh`
2. run script `scripts/generate_server.sh`

## 1. Add `indexmap` dependency in `Cargo.mustache`

### Purpose
To fix the `indexmap` [issue](https://github.com/OpenAPITools/openapi-generator/issues/12154)

### Code
```mustache
indexmap = {version = "1.9.2", features = ["std"]}
```




## 2. Derive `Model` and `Response` for structs

### Purpose
To solve the issues mentioned in https://git.cs.uni-kl.de/digivine/api/-/merge_requests/28

### Code
```mustache
#[derive(macros_lib::Model)]
```
and
```mustache
#[derive(macros_lib::Response)]
```

### Explanation
See [tests/derive_macros_test.rs](https://git.cs.uni-kl.de/digivine/api/-/blob/435805e3ad490cdce62eb3155c3c87d5ad71ac6b/tests/derive_macros_test.rs) and [tests/model_macros_test.rs](https://git.cs.uni-kl.de/digivine/api/-/blob/435805e3ad490cdce62eb3155c3c87d5ad71ac6b/tests/model_macros_test.rs) for details.

## 3. Let cargo ignore the server and client examples
### Purpose
These examples are never used but they can't successfully compile.

### Code
Removed the following code in `Cargo.mustache`:
```mustache
[[example]]
name = "client"
required-features = ["client"]

[[example]]
name = "server"
required-features = ["server"]        
```

## 4. Add response traits for general response construction
### Purpose
Many responses can be constructed by the same logic, which can be used to implement HTTP method traits. See [merge request](https://git.cs.uni-kl.de/digivine/api/-/merge_requests/35) .

### Code

In `lib.mustache`:

```mustache
pub trait AsBackendErrorResp<T> {
    fn default_code() -> &'static str;
    fn as_backend_error_resp_with_code(&self, code: String) -> T;

    fn as_backend_error_resp(&self) -> T {
        self.as_backend_error_resp_with_code(Self::default_code().to_string())
    }
}

pub trait AsBadRequestResponse<T> {
    fn as_bad_request(self) -> T;
}

pub trait NotFoundResponse {
    fn not_found() -> Self;
}

pub trait UnitSuccessResponse {
    fn succeed() -> Self;
}
```
